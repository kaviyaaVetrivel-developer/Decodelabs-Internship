# Task 1 - To-Do List


A simple command-line To-Do List application built using Python as my first internship task at Decode Labs.


## What It Can Do


- Add tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- View pending tasks
- View completed tasks
- View task summary
- Handle invalid inputs
- Display tasks with numbers


## Python Concepts Used


- Lists
- `while` loop
- `for` loop
- `match-case`
- `if-else`
- `try-except`
- `enumerate()`
- `break`
- `append()`
- `pop()`
- `len()`
- f-strings


## How It Works


The application provides a menu where the user can choose what they want to do.


========= TO-DO LIST =========
1. Add Task
2. Update Task
3. Delete Task
4. Mark Task as Completed
5. View Pending Tasks
6. View Completed Tasks
7. Task Summary
8. Exit
==============================


Completed tasks are marked with:


[✅]


The task summary displays:


Total Tasks
Completed Tasks
Pending Tasks


Sample

Enter your choice (1-8): 1


Enter the number of tasks you want to add: 2
Enter task 1: Learn Python
Enter task 2: Practice Coding


Current Task List:
1. Learn Python
2. Practice Coding


## How to Run

Make sure Python is installed, then run:


python task1.py
